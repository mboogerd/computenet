# Line budgets — a RATCHET, not a cliff.
#
# WHY. Adding text to a skill is currently free, and the log shows what free
# costs: work/SKILL.md went 668 -> 2236 lines in the twelve days to 2026-08-20,
# 3.3x, plus 21 reference files. The rubric gate has computed that number and
# warned `ideal <=500` on every run for weeks, and every session — including
# the seven-commit drain of 2026-08-20 — read the warning and proceeded. A
# warning nobody acts on is not a check.
#
# Nothing here demands a restructure. Each budget is set at the size the skill
# ALREADY IS, so today's tree passes untouched. What changes is the price of
# growth: a session that adds 40 lines must remove 40, or raise the number
# below — one line, in the diff, where a reviewer and a human can see it and
# ask what it bought. That is the question no mechanism currently asks.
#
# Lower a number whenever a drain removes text. That is the ratchet: the budget
# can fall silently and can only rise deliberately.
#
# Format: <skill-dir-name> <max-lines>
# Counted as SKILL.md's body (frontmatter excluded) plus every references/*.md,
# because the context cost of a skill is everything an agent is sent to read.
#
# Enforced by scripts/validate-skills.rb, which FAILS above the budget.
