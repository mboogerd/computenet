# 02 Dataflow semantics: assessment

## Summary
1. The operator/delta substrate is real and canonical. `kernel/.../cell/data/{op,delta,view}` holds 24 operators and 8 kernel delta types, and `:query` lowers onto these same operators. No second operator algebra exists.
2. Integration is thin at the edges. Demos mostly hand-wire 1–3 operators or none (agora, deliberate and social import zero `data.op`). `:query`, `:oracle` and `:timetravel` are test-only dependencies of the demos. The E1–E3 primitives that have landed (TaggedMapView, ReplicaFrontier, CausalStability) have zero demo adopters.
3. Interest-driven execution is real for filtering and routing (SetDelta.restrict, PartitionedShardSet), but nominal for instantiation and attention. `KeyedCells.getOrSpawn` takes no Interest, and SOC1 joins them at the demo layer (F-24). Nothing untracked or unsubscribed suspends work.
4. Guarantees compose in one place only: ExchangeCompositionExitTest covers wire, replication, partitioning and glitch-freedom, 100 seeds, with controls. It leaves out durability (separate test), Owned/Leased, joins, windows and evolution, and it needs a workaround because GroupByCell is not Replicable. Source emission epochs (the recovery×glitch-freedom seam) are unimplemented.
5. The app edge has at least 6 observation/materialization mechanisms, and 7 near-duplicate backlog ideas are still unmarked. Ownership composes only by refusal: operators skip or elide exclusives rather than carry them. The spec status lines are stale in both directions.

## Integration gaps
1. **Interest does not drive instantiation or attention.** Evidence: `doc/demo-findings.md:1496` (F-24); `KeyedCells.kt:71`; `InstanceIndex.kt:71-77` records only; the workaround is demo-side (`demo/social/.../InterestDrivenFamily.kt`). This blocks a demo whose subscribers pull remote/keyed computation into existence, which is the vision's core premise (01-vision:38). **H**. Status: **untracked** at kernel level (only closed SOC1 tasks exist; SOC3c `computenet-6a2.3` is north-star).
2. **Durability is absent from the composition gate.** Evidence: `ExchangeCompositionExitTest.kt:77-79` defers to a separate two-JVM test; source emission epochs (22 I-14) have 0 code hits; `computenet-638io` (crash re-emits onto an evicting cell's late outlet); `computenet-bv7qb` (unpark re-journals). This blocks a demo combining recover + replicate + glitch-free + windows. **H**. Status: partly tracked (638io, bv7qb); the epoch rule and the composed gate are **untracked**.
3. **GroupByCell (and derived aggregates generally) are not Replicable.** Evidence: `ExchangeCompositionExitTest.kt:63-69` workaround; the Replicable implementers are only SetCell/OrMap/PnCounter/MergeableGroupBy/Watermark/Shard. This forces an input-replication recompute design in every replicated demo. **M**. Status: **untracked** (no bead matches).
4. **Ownership does not traverse operators or demos.** Evidence: `GroupByCell.kt:132-139`, `SetCell.kt:1340`; 23:3 taps/recovery unimplemented; 0 demo uses; 1 concord scenario. This leaves no path to show exclusive payloads (e.g. work items, leases) through a pipeline. **M-H**. Status: partial (`computenet-u6np` is minor; G-47 admit half); the operator-level exclusive transport is **untracked**.
5. **App-edge observation is fragmented.** Evidence: 6+ kernel mechanisms (table); demos split across two styles; 7 unmarked backlog duplicates. Each demo picks a different consistency level at the edge, and an all-features demo gets torn views (F-5/F-27). **M**. Status: KE2 open (4 children); backlog consolidation **untracked**.
6. **Independent-root views cannot be wave-aligned.** Evidence: F-27 (`demo-findings.md:1765`); shopping keeps 3 views point-consistent. **M**. Status: KE2 `computenet-lw0mv` covers only the rejection side.
7. **No batch-as-one-wave across cells.** Evidence: F-19/F-22 (`demo-findings.md:932,1139`); `computenet-3ylve` P4. This forces demos to expose intermediate states per outlet. **M**. Status: tracked at P4 as a demo decision; the kernel primitive is **untracked**.
8. **Landed primitives have no adopters.** Evidence: TaggedMapView, ReplicaFrontier (exchange test only), CausalStability and StabilityReclaim have 0 demo main uses; `:query`/`:oracle`/`:timetravel` are test-only. **M** (unproven integration). Status: **untracked**.
9. **Cycles unbuilt.** Evidence: `LoopContext` has 0 hits; KE5 has 0 children; agora hand-rolls cycle heads (F-17). This blocks glitch-free/fixpoint semantics in agora/deliberate. **M**. Status: tracked (KE5, QRY2), not broken down.
10. **Spec and backlog status prose disagrees with code.** Evidence: `24-data-cells.md:3` calls the OR-map "unbuilt"; 96 E1–E3 headers say PROPOSED; E4 says LANDED while KE4 is open. This misleads autonomous agents choosing work. **L**. Status: **untracked**.
11. **Dataflow gap rows in CONCORDANCE: 29.** These are joins, outer joins, partition/shard, tag epochs, WL-04/15/17/18 and GF-03. The distributed/partitioned operator claims have no executable arbiter. **M**. Status: partly (`computenet-tcovt`).

## Bridging proposals (ordered)
1. **(M) All-natures composition gate v2.** Extend ExchangeCompositionExitTest, or add a sibling, so that journal + kill/restart run in the same graph as wire/repl/partition/glitch-free, plus one join and one waterline window. Implement the 22 I-14 source-emission-epoch rule it will expose. This is the executable definition of "all features together".
2. **(S) Status truth pass.** Fix the 24:3 and 96 E1–E5 headers. Mark the 7 observation backlog items as absorbed/implemented or map them to KE2. Reconcile KE4 against its "LANDED" label.
3. **(M) One canonical app-edge observation API.** Make `observeAligned`/`host.observe` the documented default. Re-express the data/view hubs as an implementation detail. Migrate slotfinder, dialogue and backlog-triage. Resolve F-27 (per-root alignment groups with explicit cross-root staleness disclosure).
4. **(M) Kernel Interest→spawn seam.** Lift `InterestDrivenFamily` into `KeyedCells`/`LocationRegistry` (spawn on admitted interest, host-thread-safe), with concord scenarios. Follow with an attention-based park/suspend of unsubscribed subgraphs.
5. **(M) Replicable aggregates.** Make GroupByCell Replicable via MergeableGroupBy semantics, or declare officially that aggregates recompute from replicated inputs and encode that in the `graph {}` DSL.
6. **(M) Cross-cell batch-as-one-wave ingress** (F-19/F-22), so multi-outlet writes land as one wave.
7. **(L) Ownership through operators.** Specify and implement exclusive transport through Filter/FlatMap/Join (take/forward/discharge accounting), plus a demo that moves Owned work items across a partitioned pipeline. Close the G-47 admit half.
8. **(M) Adopt, don't add.** Rebuild one flagship demo's runtime graph via `query {}` (skillmatch, where F-20 is nearly equal). Wire TaggedMapView into tiering (E1.6), and ReplicaFrontier/CausalStability into exchange Main.
9. **(L) KE5 breakdown and implementation.** Implement LoopContext and fixpoint heads, with agora as adopter. Defer E6 Z-sets and file an epic so it stops being untracked.
